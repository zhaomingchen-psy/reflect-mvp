# REFLECT MVP · 本地运行

> 平台名 **REFLECT**（Reflective Empathy Feedback via LLM-Enabled Client Training）。PsyCLIENT 是上一篇论文的名字，本平台与 RCT 一律用 REFLECT。

## 双语

右上角 中文 / English 切换，选择存在浏览器本地。两种语言各有独立的题库（`items.json` / `items_en.json`）、案例、教学页与提示词——英文内容是按英语母语大学生口语原创的，不是中文直译；评价器结构完全一致（同一套两步机械判定），因此判定在两种语言间可比。

上线部署见上一级目录的《部署上线指南.md》。

## 启动（只需 Python 3，无任何依赖）

```bash
cd Desktop/Psyclient培训/skills/mvp/app
python3 server.py
```

浏览器打开 **http://localhost:8000**。换端口：`python3 server.py 8001`。

`.env` 已放在上一级目录（`skills/mvp/.env`）。当前全部任务统一使用 **glm-4.6（关思考链）**——判定回归 18/18，判定/生成约 4–9 秒/次。代码支持按任务分模型（`MODEL` 管判定与润色、`MODEL_GEN` 管来访者与小结），若嫌等待久可把 `MODEL` 改回 glm-4-plus（同为 18/18，快约一倍），编辑 .env 后重启即可。

## 练习流程

每个模块 = 结构化练习题 + 对话练习，对应《研究设计》的两个环节。

**结构化练习题**：看示范与定义 → 逐题作答：写回应 → 自评 0–10 → 提交 → 督导反馈（命中／部分命中／脱靶 + 点评 + 改写方向）→ 未命中可修改重写（每题最多 3 次）。

**对话练习**（做完题目后进入，也可从首页直接跳入）：与模拟来访者对话 6–12 轮。
会谈中**没有任何提示与反馈、不可重写**——唯一的反馈是来访者的自然反应：被准确反映会慢慢打开，被建议/宽慰会收住。
结束后进入复盘：命中统计 + 非处方小结（命中模式/改进方向/关键时刻）+ 回放 2–3 个时刻（**先自己判断接没接住，再揭示来访者当时的内在状态**）。

对话中另有**"帮我改得更共情"**按钮：对还没发出去的草稿请求一次润色（建议句 + 一句理由），可采纳（仍可编辑）或保留原句。润色器**看不到来访者的内在状态标注**——只基于说出口的对话改写，不会把答案漏给学员。每次润色请求、以及发送的话是否采纳了建议（exact/edited），全部落日志，用于依赖分析。

技术要点：来访者话轮**先定内在状态、再生成话语**（状态即复盘时的答案卡）；标注在会谈中绝不下发前端，复盘时才可见；全部学员话轮在会谈结束后用 v3.2 评价器并行评分。

设计约束都已内建：反馈只在作答后出现；改写建议只给方向、不给可照抄的句子；hit 时的建议显示为"更进一步（选做）"，与改错区分。

## 标准化评估（SCA，前后测用）

首页底部的"标准化评估"入口（A 卷 / B 卷），**由主试安排时才进入**，日常练习不用。
与练习的差别：固定案例（学员没练过的人物）、固定 **10 个学员话轮**、无润色、无反馈、无复盘——满 10 轮自动结束，只显示"评估完成"。
A/B 为平行卷（同为"重要关系疏远 + 轻描淡写掩饰"结构，人物不同），前测 A、后测 B，或按被试平衡轮换。
数据落 `app/logs/sca_日期.jsonl`：逐轮即时写入（防中途关页面丢数据），会谈结束再写完整记录（含全部内在状态）。
给专家盲评 TES 时**只导出 history（对话原文），不给 states**；states 留作 EA% 过程分析。

## 示范式反馈（"看一个示范句"）

反馈面板底部有一个 **看一个示范句** 按钮——**必须学员主动点击**才出现示范，不会自动跳出来。这是《研究设计》里"示范式反馈"的实现，对应元分析中的"观察"成分，同时满足两条硬约束：示范只在学员作答之后出现；索取行为逐次落日志，可用于依赖性分析。

**褪除规则**（对应研究设计的 W1–2 每题、W3 仅未命中、W4 不给）：

| 模块 | 是否可看示范 |
|---|---|
| 内容反映（≈W1） | 每题都可看 |
| 情感反映（≈W2） | 每题都可看 |
| 意义反映（≈W3） | **仅在未命中时**可看；命中则显示说明 |
| 对话练习（≈W4） | 不提供示范（会谈中另有"帮我改得更共情"，那是改写学员草稿，不是示范） |

前后端各有一份同样的规则（`prompt.py: example_allowed` 与 `index.html: EX_OK`），服务端会拒绝越权请求（403）。

示范由模型针对该话轮生成，**只给样例、不评价学员的句子**（提示词里明令"看不到也不需要看学员写了什么"），并附一句"这句示范做到了什么"。示范卡尾部固定提示"只供对照、不必照抄"。

日志：`logs/log_日期.jsonl` 中 `type=example_shown` 的记录，含 item、skill、lang、attempt、请求时的 verdict、示范原文与耗时——依赖分析所需的字段齐备（可算词汇重合度、看谁在什么档次下索取示范）。

## 跨会话学习目标

每次对话练习复盘后，督导小结里的"改进方向"会自动存为该学员的**当前练习方向**（`logs/goals.jsonl`），并在首页、练习页、对话页顶部置顶显示（"本周练习方向"）。下一次复盘开始时先问"上次的方向有进展吗"（有进展/还没有/说不好，落 annotations 日志，key 前缀 goalcheck:），然后新方向替换旧方向。这是刻意练习文献中 learning goal 环节的实现（Larsson et al., 2025 的流程）：反馈不再只属于单题，而是跨会话携带。SCA 评估模式不显示目标（保持标准化）。

## 学员身份

首次打开会要求输入姓名或学号（存在浏览器本地，右上可切换）。此后所有数据——练习题作答、对话会谈、润色使用、复盘自判——都带学员标识落日志；/review 页可按学员筛选。多人共用一台电脑时各自输入自己的名字即可。注意：这只是标识、不是认证，正式部署到服务器时再加真正的登录。

## 复盘标注（研究者用）

http://localhost:8000/review ——逐条核对模型判定，标"同意/不同意+改判+备注"，页顶实时显示人工同意率。标注存 `logs/annotations.jsonl`。

## 数据

结构化练习：`app/logs/log_日期.jsonl`（时间、题目、第几次作答、自评分、原文、完整反馈、耗时）。
对话练习：`app/logs/conv_日期.jsonl`（完整对话、每个来访者话轮的内在状态、全部评分、小结、关键时刻、understood 曲线）。
复盘标注：`app/logs/annotations.jsonl`（含学员在复盘中的自判记录，key 前缀 debrief:）。

## 加题

编辑 `app/items.json`，每题字段：`id`、`skill`（content/feeling/meaning）、`background`、`context`、`utterance`、`surface`、`emotions`、`meaning`。后三个是隐藏标注，**服务器不会下发给前端**。当前三道为虚构占位题，正式题目从真实语料替换。

## 已验证

- 三个端点通（页面、题目、反馈），标注不泄漏给前端
- 反馈判定用 v2 提示词（自检 9/9），单条约 3–7 秒
- 空回应拦截、解析失败重试一次并有兜底文案
- 服务只监听 127.0.0.1，不对外
